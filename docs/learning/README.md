# B4-1 입문 학습자료 — Linux 시스템 운영과 셸 자동화

> 학습 목적: **컴퓨터가 알아서 자기 상태를 점검하게 만들기** 미션의 요구사항을 스스로 이해하고 설명하기  
> 대상: 터미널·Linux·Bash를 처음 배우는 입문자(중학생 수준의 기초 설명)  
> 진행: **상세 학습 → 안전한 실습·질문 → 실제 출력 확인 → 증빙 캡처 → 미션 스토리 제작**

## 학습 원칙

- 강의의 비유·질문·표·구조도·명령 설명을 **임의로 요약·삭제하지 않는다**.
- 질문이 나오면 문서를 확장한다. 보충 설명이 길어지면 심화편으로 분리하고 원문에서 링크한다.
- 중요한 명령은 **원문 → 구성 요소별 풀이 → 전체 한국어 해석 → 실제 결과·미션 연결** 순서로 설명한다.
- 이 폴더의 문서는 **학습교재**다. 공식 수행 내역서와 프로그램 소스를 대체하지 않는다.
- 제출 캡처는 원리를 이해한 다음 안전하게 실행하고 촬영한다.
- 미션 스토리는 **학습 완료 후** 별도 저장소 `codyssey-mission-tech-glossary`에서 시각 중심으로 만든다.
